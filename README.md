How to read this page ?
-Part I opens with a map of the scholarship and then lists the primary and secondary sources. 
-Part II presents each primary witness in three layers: a description card, the actual text as transmitted by that witness (left, in Chinese), and a working English translation (right). Variant readings are underlined in cinnabar on both sides — the Chinese character and the English word that renders it — so the textual genesis of the poem can be read directly off the page. 
-Part III sets out the draft index, kept strictly to the two perspectives agreed in the meeting.
